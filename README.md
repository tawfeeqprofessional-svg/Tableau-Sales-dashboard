📊 Tableau Sales Dashboard – Worldwide Sales Analysis

📌 Project Overview

This project showcases an interactive Worldwide Sales Dashboard developed using Tableau. It provides a visual approach to exploring sales data and understanding business performance through data visualization.

🎯 Project Objectives

- Analyze worldwide sales data.
- Understand sales performance and business trends.
- Present data through interactive visualizations.
- Support data-driven business decisions.
- Make complex sales information easier to understand.

🛠️ Tools & Technologies

- Tableau Public
- Data Visualization
- Data Analysis
- Business Intelligence

📈 Dashboard Features

- Interactive sales dashboard.
- Worldwide sales data visualization.
- Business performance analysis.
- Visual representation of sales trends.
- Easy-to-understand dashboard layout.
